# Nine Lives Audio — 优化与中文本地化说明

> 本文档记录本轮的优化项、本地化架构、以及如何自检与打包。
> 所有结论都可用 `python tools/verify.py` 复现，无需 Windows 环境。

---

## 1. 本地化（English / 简体中文）

### 1.1 设计

| 组件 | 作用 |
| --- | --- |
| `Models/AppSettings.Language` | 持久化偏好：`system` \| `en-US` \| `zh-CN`，默认 `system`（跟随系统） |
| `Services/ILocalizationService` | `GetString` / `Format` / `SetLanguageAsync` / `RefreshFromSettings` / `CurrentLanguage` / `IsChinese` / `LanguageChanged` |
| `Services/LocalizationService` | 代码式双语资源（245 个 key，中英一一对应），无 `.resw`/PRI，打包零风险 |
| `Helpers/AppLanguage` | 环境语言标志，供 `TimeFormatHelper`、`AudioBook` 等无 DI 的静态/模型代码使用 |
| `Helpers/Loc` | XAML 附着属性 `loc:Loc.Text/Content/Header/Placeholder`，语言切换后原地刷新 |

切换路径：设置页 → 外观 → 语言 → `SettingsViewModel.ApplyLanguageCommand` →
`SetLanguageAsync`（写设置 + 置 `AppLanguage`）→ `LanguageChanged` →
`Loc.ReapplyAll()` ＋ 各页面 `ApplyLocalization()`，**无需重启**。

### 1.2 用法

```csharp
// C#
Title = _localization.GetString("LibraryTitle");
Message = _localization.Format("DaysAgo", 3);
```

```xml
<!-- XAML：不需要代码后台 -->
<Button loc:Loc.Content="SaveSettings"/>
<ToggleSwitch loc:Loc.Header="HideFinished"/>
<TextBox loc:Loc.Placeholder="EnterUsername"/>
```

### 1.3 规则（由自检脚本强制）

1. 新增 key 必须**同时**写入 `en-US` 与 `zh-CN` 两个字典，否则 `verify.py` 失败。
2. `Format` 模板里的 `{0}`… 数量必须与调用点实参数量一致。
3. `loc:Loc.*` 只能用在支持对应属性的控件上（`TextBlock->Text`、`Button->Content`、
   `ToggleSwitch/ComboBox/TextBox/PasswordBox->Header`、`TextBox/PasswordBox/ComboBox->Placeholder`）。
4. 使用 `loc:` 的文件必须声明 `xmlns:loc="using:NineLivesAudio.Helpers"`。

## 2. 本轮修复清单

### 2.1 P0（安全 / 稳定性 / 数据正确性）

| 问题 | 修复 |
| --- | --- |
| 登录时把明文密码与 Token 写进调试输出 | 删除 `AudioBookshelfApiService` 全部 `Debug.WriteLine`，`LastError` 不再包含响应体 |
| 登录把共享 `HttpClient.Timeout` 改成 30s，影响下载/同步 | 改为单次 `CancellationTokenSource(30s)` |
| 崩溃钩子里 `GetAwaiter().GetResult()` 可能死锁 | 改为 `FlushLogsBestEffort`（2s 上限、永不抛） |
| SQLite 单连接并发访问 → `database is locked` / 数据竞争 | `SemaphoreSlim` 串行化 26 个公开方法 + `WAL` + `busy_timeout=5000` + `Pooling=True` |
| **自检发现的死锁**：`UpdateXxxAsync` 持锁后再调 `SaveXxxAsync`（同锁）→ 永久挂起 | 抽出 `SaveXxxCoreAsync`（不加锁），批量写入同样改用 core 版本 |
| **自检发现的 DI 缺陷**：`AppInitializer` 依赖具体类 `LocalizationService`，容器只注册接口 → 启动即抛异常 | 改为依赖 `ILocalizationService`，接口新增 `RefreshFromSettings()` |
| **自检发现的 XAML 缺陷**：`SettingsPage.xaml` 出现两个 `x:Name="TestConnectionButton"` → 无法编译 | 第二个改名为 `DoctorTestConnectionButton` |
| 版本三方不一致（csproj `net9` / 脚本 `net10` / README `.NET 10`） | 统一为 .NET 9，脚本与 README 一并修正 |

### 2.2 性能

- 封面图：内存缓存（上限 300）+ 按用途限制解码尺寸（卡片 300、迷你播放器 160、详情/播放器 800），滚动不再重复解码 2MB 原图。
- 画刷：`HoursToCosmicBrushConverter` 按颜色缓存；首页卡片悬停不再每次 `new SolidColorBrush`。
- 章节定位：`AudioBook.GetCurrentChapterIndex` 线性扫描 → 二分查找 `O(log n)`。
- 搜索：`ContinueWith` + `TaskScheduler.Default` 改为 `async/await` + 可取消 `CancellationTokenSource`。
- 日志：启动时清理 14 天前的 `app_*.log`；`FlushAsync` 由「猜 200ms」改为消费者确认回执（上限 2s）。
- 同步定时器：`async void` 回调改为 `_ = SyncNowAsync()`（内部已有 `_syncLock` 与 try/catch）。
- 清理缓存时一并清空封面内存缓存。

### 2.3 工程化

- `.editorconfig`、`.github/workflows/build.yml`（Linux 静态自检 + Windows 构建 + publish）。
- `Properties/PublishProfiles/win-x64.pubxml`：自包含发布到 `binpublish`，与 `installer.iss` 对齐（此前 csproj 引用了不存在的 pubxml）。
- `tools/verify.py`：纯 Python 静态自检（见第 3 节）。
- `tools/package.ps1`：Windows 一键 自检 → 还原 → 构建 → 发布 →（可选）Inno Setup 打包。
- `.gitignore` 增加 `Logs/`、`Exports/`、`*.log`。

## 3. 自检（`tools/verify.py`）

```bash
python tools/verify.py
```

12 组检查，全部离线、跨平台：

1. 所有 `.xaml` / `.csproj` 是良构 XML
2. C# 花括号/圆括号/方括号配平（忽略字符串与注释）
3. 单个 XAML 内无重复 `x:Name`
4. XAML 引用的事件处理器在代码后台存在
5. 控件名/成员交叉校验
6. 本地化 key：中英集合一致，且代码/XAML 引用的 key 都存在
7. `Format` 实参数量与模板占位符一致
8. `loc:Loc.*` 与控件类型匹配
9. DI 图：所有构造函数依赖都已在 `App.xaml.cs` 注册（且不会依赖「注册为接口」的具体类）
10. 应用 XAML 引用的 `StaticResource/ThemeResource` key 都有定义
11. 打包一致性：资源文件、发布配置、TFM 三处一致（csproj/脚本/README）、`installer.iss` 版本与输出目录一致
12. XAML 命名空间声明（`xmlns:loc` 必须存在，`using:NineLivesAudio.*` 必须指向真实命名空间）

当前状态：**✓ all checks passed**（83 个 C# 文件 / 13 个 XAML / 245 个本地化 key）。

## 4. 封装测试（Windows 上执行）

```powershell
# 一键：自检 -> restore -> build -> publish -> 安装包
powershell -ExecutionPolicy Bypass -File tools\package.ps1 -Installer
```

产物：
- `bin\Release\net9.0-windows10.0.22621.0\win-x64\` — 构建输出
- `binpublish\` — 自包含发布（含 Windows App SDK 运行时）
- `installer_output\NineLivesAudioSetup.exe` — Inno Setup 安装包

手工验证顺序建议：
1. 首次启动 → 应跟随系统语言（中文系统直接中文界面）
2. 设置 → 外观 → 语言 → 切到「English」/「简体中文」→ 导航栏、设置页、状态提示、播放页标签立即变化
3. 重启应用 → 语言保持上次选择（`settings.json` 中 `Language` 字段）
4. 书库有书时切换语言 → 空状态文案、章节标签、时长（`时/分`）同步变化

## 5. 已知限制 / 后续建议

- **本环境无 Windows SDK 与 .NET SDK**：无法执行 `dotnet build`；已用 tree-sitter C# 语法解析 + 上述 12 组静态检查覆盖，但语义级编译仍需在 Windows 或 CI 上确认。
- `AudioPlaybackService`（约 1300 行）、`AudioBookshelfApiService`（约 950 行）仍是 God Class，建议按「会话/轨道/统计」拆分。
- 下载无断点续传（失败即删 `.part`），建议改为 HTTP Range + 保留临时文件。
- 仍无单元测试项目：`NineLivesAudio.csproj` 已保留 `InternalsVisibleTo("NineLivesAudio.Tests")`，建议新增 xUnit 项目并用内存 SQLite 测试 `LocalDatabase`。
- 首页 `LogoImage` 使用 1.9MB 原图，可压缩为 WebP/更小 PNG。
